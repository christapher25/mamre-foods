# C1: Release signing, version scheme, keystore script, minSdk report (DEV-C)

Goal: Doc 4 F1 and F5 groundwork. A signed release APK when the owner's key is present; unsigned in CI.
Branch: feat/android-release-signing from origin/main.
Allowed paths: android/app/build.gradle.kts (signing and version blocks only, smallest diff), android/version.properties (new), android/.gitignore and the root .gitignore (key files only), tools/release/** (new), android/buildSrc/** (only if a check is added there), tests, docs/DECISIONS.md, docs/QUESTIONS.md.
New dependency: none.

Build:
1. android/version.properties with versionCode and versionName (start: versionCode 1, versionName 1.0.0-rc1). build.gradle.kts reads it. A Gradle task printVersion prints both.
2. Signing: if android/keystore.properties exists (storeFile, storePassword, keyAlias, keyPassword), the release build is signed with it; if it does not, the release stays unsigned and the build still passes (CI). keystore.properties and *.jks, *.keystore are git-ignored. Passwords never appear in logs.
3. tools/release/make-keystore.ps1: uses keytool from C:\Program Files\Android\Android Studio\jbr\bin. Creates %USERPROFILE%\mamre-keys\mamre-release.jks (RSA 4096, validity 30 years, alias mamre), asks for the password twice without echo, writes android\keystore.properties pointing to the file, and prints in plain words: "Copy C:\Users\<you>\mamre-keys\mamre-release.jks to a USB stick and to your Google Drive. If this file is lost, the app can never be updated without deleting all its data." It refuses to overwrite an existing key.
4. tools/release/build-release.ps1: checks keystore.properties exists, runs assembleRelease, runs apksigner verify --print-certs on the APK, copies it to C:\dev\mamre-team\out\release\mamre-<versionName>.apk and prints the SHA-256 of the APK and of the signing certificate.
5. A Gradle check verifyReleaseSigning that runs only when keystore.properties exists: fails if the release APK is unsigned or signed with the debug key.
6. minSdk report: write minSdk, targetSdk and compileSdk into DECISIONS.md, and the lowest Android version that minSdk allows. If minSdk is above 26 (Android 8), say what would need to change to reach 26; do not change it.

Tests: a unit test (or a Gradle test with a throwaway keystore created in build/) that a signed build verifies and an unsigned build still assembles; version.properties parsing.
Mutation proofs: signing config always skipped when the file exists; verifyReleaseSigning accepting the debug key.
Evidence: the commands and exit codes, apksigner output for a test-key build (no real key exists yet), the minSdk report.
Out of scope: creating the real key (that is O1, the owner), Play Store, CI secrets.
